## PROYECTS:

### 🧬 BRCA1/BRCA2 Variant Analysis

#### Master's Thesis — Python · Ensembl VEP API · Data Analysis

Analysis of hereditary pathogenic variants in BRCA1 and BRCA2 associated with hereditary breast and ovarian cancer.

The project combines a systematic literature review with computational analysis of genetic variants. A Python script was developed to process variants reported in the literature, reconstruct complete HGVS nomenclature, query the Ensembl Variant Effect Predictor (VEP) API programmatically, and compare the resulting annotations with information collected from the literature.

[View proyect ->](https://github.com/mizquierdoperez/Variantes-patog-nicas-hereditarias-en-BRCA1-y-BRCA2-revisi-n-bibliogr-fica-y-an-lisis-bioinform-tico)
